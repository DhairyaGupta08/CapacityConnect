# SIH Demo Script (8–10 Minutes)

| Time | Step | Highlights |
|---|---|---|
| **0:00** | Problem Framing & Public Portal | Sober government portal, course catalog, public certificate verification |
| **0:30** | Trainer Registration | Live register trainer, "Awaiting approval" status gate |
| **1:15** | Admin Governance | Admin logs in, reviews KPI dashboard, approves trainer |
| **2:15** | Course & Assessment Authoring | Trainer creates course, adds modules, attaches PDF & video, creates timed MCQ assessment |
| **4:15** | Trainee Experience | Trainee discovers course, enrolls, consumes resources, attempts MCQ assessment, auto-grades |
| **6:00** | Certification | 100% completion rule evaluates, PDF certificate issued, public verification via QR/code |
| **6:45** | Feedback & Monitoring | Trainee submits rating/review, trainer monitors analytics |
| **7:30** | Competency Matching | Admin defines requirement, runs weighted matching with explainability breakdown & coverage |
| **8:30** | Comms & Audit | Targeted announcements, in-app notification bell, audit logging |
| **9:15** | Architecture & Wrap | Modular monolith, security, phase 2 roadmap |
